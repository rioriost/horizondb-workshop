## 1. Check extensions and models (2 minutes)


Require `azure_ai >= 2.5.6`, `vector`, `pg_diskann`, `pg_textsearch`, `pg_durable`, `age`, and aliases `default-embedding`, `default-reranker`, `default-chat`. Display only model alias, name and status—not keys or endpoint configuration. Managed model names can change; use their aliases.

If any model is absent or not usable yet, check [first-time enablement and terms acceptance](01-deploy.md#first-time-horizondb-deployment), then wait for readiness. Successful `azd provision` alone does not guarantee model readiness. To repeat only the model check, use this SELECT rather than rerunning the entire script, which includes DDL:

```sql
SELECT alias, model_name, status FROM model_registry.model_list_all()
WHERE alias IN ('default-embedding', 'default-reranker', 'default-chat');
```

The script checks current `ai.search` arguments and `ctid` output and stops when unavailable. Consult the [official migration guide](https://learn.microsoft.com/azure/horizondb/ai/migrate-ai-schema) for older versions; upgrade only after the instructor confirms availability. `CREATE EXTENSION` cannot install functions not yet distributed by the service.

## 2. Generate embeddings and indexes (3 minutes)

```sql
\i sql/03-embeddings.sql
```

Embed one Japanese sentence, then a batch of two English sentences. Scalar `ai.embed(text => ...)` returns `real[]`; array input returns a row per embedding. Cast to `vector(1536)` for storage.

Embed all 18 descriptions and create cosine DiskANN and English BM25 indexes. Expect `products=18, embedded=18, min_dimensions=1536, max_dimensions=1536`. Use identical models and dimensions for stored documents and queries. This small dataset cannot demonstrate index performance benefits.

## 3. Search and rerank (4 minutes)

```sql
\i sql/04-search.sql
```

| Query | Observe |
| --- | --- |
| pgvector `<=>` | Search for a chair using Japanese; **smaller** cosine distance is closer |
| `ai.search(search_type => 'fulltext')` | English BM25 keyword search; no inference with `rerank=false` |
| `ai.search(search_type => 'hybrid')` | Combine BM25 and vectors with RRF; **higher** scores rank first |
| Same search with `rerank => true` | Rescore candidates for semantic relevance |
| Outer `WHERE` | Retain chairs costing at most 200 USD |

Compare products and latency before/after reranking. Rankings need not change. Vector, BM25, RRF and reranker scores have different scales; do not compare raw values across modes.

**Important:** Native `ai.search` returns `TABLE(ctid tid, match_type text, score real)`. Join through `p.ctid = s.ctid` **in the same statement**, then return the durable primary key `p.id` to your app. Never persist `ctid`, which can change after updates.

An outer `WHERE` filters **after retrieval**. It is not pre-filtered category retrieval or an authorization mechanism. For this 18-row dataset we retrieve all rows to avoid losing qualifying candidates. At scale, use [filtered retrieval SQL](https://learn.microsoft.com/azure/horizondb/ai/hybrid-search). Successful hybrid execution alone does not prove both methods ran; inspect `pg_indexes` and `match_type`.

BM25 uses `english`; use English keyword queries. The Japanese example uses multilingual vector embeddings, not a guarantee of Japanese full-text search quality.

## 4. Try each direct AI function (3 minutes)

```sql
\i sql/05-ai-functions.sql
```

`ai.rank()` directly reranks ten vector candidates. Construct `data` and `ids` arrays in **the same ID order**, then join returned IDs to products. Without `ids`, returned IDs are zero-based input positions, not product primary keys.

Then extract material/style as JSONB with `ai.extract()`, evaluate reading suitability with `ai.is_true()` and generate a Japanese recommendation with `ai.generate()`. `is_true` can return `NULL` when inconclusive. Inference is probabilistic, not verification of pricing or safety facts. Check that the recommendation does not invent catalog information.

## 5. Durable AI pipeline (3 minutes)

```sql
\i sql/06-pipeline.sql
SELECT * FROM ai.status('workshop_embeddings');
\watch 2
```

Use only three rows for `chunk_step → embed_step → table_sink`. `ai.run()` submits asynchronously; wait until `last_run_status` is `completed` or `failed`. Ctrl+C stops `\watch`, not the pipeline.

On failure, inspect status with the instructor instead of assuming success from row counts. After completion:

```sql
SELECT count(*) AS chunks, count(embedding) AS embedded,
       min(vector_dims(embedding)), max(vector_dims(embedding))
FROM workshop.pipeline_output;
```

Expect `3, 3, 1536, 1536` because the descriptions are short. `*_step()` builds deferred work; unsuffixed AI functions invoke inference immediately. `incremental_column => 'updated_at'` controls checkpoints; advance it whenever a change needs reprocessing. This exercise uses manual execution. For automatic ingestion, combine `on_change` with an initial `ai.run()`.

Chunk `doc_id` is batch-local, not a product primary key. This pipeline output is educational; the application uses the product embeddings generated earlier.

## 6. Connect graph retrieval (2 minutes)

```sql
\i sql/07-graph.sql
\i sql/08-verify.sql
```

Create `(:Product)-[:HAS_STYLE]->(:Style)-[:SIMILAR_TO]-(:Style)` and use Cypher to find neighboring styles for product 1. Expect **18** product nodes and **six** mid-century neighbors for the scandinavian seed. Join primary keys back to SQL for prices/categories. Style relationships are defined deterministically from fictional data, not inferred by AI.

`08-verify.sql` checks 18 embeddings, both BM25/DiskANN indexes, three models, three completed pipeline output rows and 18 graph products.

## Troubleshooting

For `not allow-listed`, check `azure.extensions`. For preload errors, check `shared_preload_libraries` and restart completion. Missing `ai.search` requires checking extension/service availability. For model authentication, 429s or timeouts, check model status and quotas. Do not ignore failures. After correcting configuration, rerun only the failed statements: repeating entire DDL scripts conflicts with existing objects.
